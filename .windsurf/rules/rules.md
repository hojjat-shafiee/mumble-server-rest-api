# Windsurf Cascade Rules — mumble-server-rest-api

## Project Context
- **Name**: `mumble-server-rest-api`
- **Stack**: FastAPI + ZeroC Ice 3.7 RPC for Murmur VoIP Server administration
- **Validation**: Pydantic v2
- **Testing**: Pytest with mock ZeroC Ice stubs (`tests/mock_ice.py`)

## Core Agent Directives
1. **Synchronous `def` for Ice RPC**:
   - ZeroC Ice RPC methods are blocking. Always use standard synchronous `def` for FastAPI endpoints calling Ice. FastAPI dispatches synchronous endpoints to Starlette's threadpool (`run_in_threadpool`).
   - Do NOT use `async def` for routes calling Ice proxies.
2. **Error Handling**:
   - Wrap all routes calling Ice with `@handle_ice_errors` from `app.exceptions`.
3. **Route Order**:
   - Static routes (`/servers/version`, `/servers/deleteServers`, `/servers/userCount`) must be registered before parameterized routes (`/servers/{id}`).
4. **Authentication**:
   - Mutating routes (`POST`, `PATCH`, `DELETE`) require `_auth: bool = Depends(verify_api_key)`.
5. **Testing & Verification**:
   - Run `pytest` to verify changes. All tests use mock Ice fixtures in `tests/conftest.py` and require no live Murmur server.
6. **Immutable Files**:
   - Do not edit `Murmur_ice.py` (auto-generated by slice2py).
