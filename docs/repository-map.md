## 1. High-Level Architecture Flow

```
HTTP Client (Port 2332)
   │
   ▼
[main.py: FastAPI Application & Lifespan]
   │
   ├──▶ [/healthz, /] (Simple async health probes)
   │
   └──▶ [app/server_router.py] (REST Resource Endpoints)
           │

           ▼
        [app/ice_manager.py: get_ice_meta Dependency]
           │
           ▼
        [ZeroC Ice 3.7 RPC / Murmur.ice Stubs]
           │ (TCP Port 6502)
           ▼

```

## 3. Route Order Map (`app/server_router.py`)

Static routes **must** remain defined before dynamic parameterized routes to prevent path-parsing errors (`422 Unprocessable Entity`):

```text
1. GET  /servers/version        <-- STATIC (Must precede /{id})
2. POST /servers/deleteServers  <-- STATIC (Batch delete)
3. GET  /servers/userCount      <-- STATIC (Global user count)
4. GET  /servers                <-- Collection Root
5. POST /servers                <-- Create Server
6. GET  /servers/{id}           <-- Dynamic Parameterized
7. DELETE /servers/{id}         <-- Dynamic Parameterized
8. PATCH /servers/{id}          <-- Dynamic Parameterized
9. POST /servers/{id}/start     <-- Sub-resource Action
10. POST /servers/{id}/stop     <-- Sub-resource Action
11. POST /servers/{id}/restart  <-- Sub-resource Action
12. GET  /servers/{id}/logs     <-- Sub-resource Logs
...
[Legacy Compatibility Routes with include_in_schema=False at bottom]
```

## 4. Agent Safe-to-Edit vs Off-Limits Matrix

| Component | Status | Guidance for Agents |
| :--- | :--- | :--- |
| `app/server_router.py` | **Safe** | Ensure `def` (sync), `@handle_ice_errors`, and static routes stay on top. |
| `app/models.py` | **Safe** | Use Pydantic v2 `ConfigDict` and explicit `Field` types. |
| `app/utils.py` | **Safe** | Preserve `obj_to_dict` handling of `__slots__` and primitives. |
| `tests/test_api.py` | **Safe** | Keep tests hermetic using `mock_ice_meta`. |
| `tests/mock_ice.py` | **Safe** | Mirror real Murmur Slice method signatures and return types. |
| `Murmur_ice.py` | **OFF-LIMITS** | Generated file. Never edit manually. |
| `Murmur.ice` | **OFF-LIMITS** | Upstream ZeroC Slice definition. |
