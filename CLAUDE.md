Guidance for Anthropic Claude Code and related AI agents working in `mumble-server-rest-api`.

## 1. Project Overview & Tech Stack
- **Project**: Modern FastAPI REST API wrapper around ZeroC Ice RPC for administering Murmur (Mumble server).
- **Language & Runtime**: Python 3.11+
- **Framework**: FastAPI (v0.111+), Starlette, Uvicorn
- **Validation**: Pydantic v2 (`ConfigDict`, `BaseModel`)
- **RPC / Protocol**: ZeroC Ice 3.7 (`Murmur.ice`, `Murmur_ice.py`)
- **Testing**: Pytest with mock ZeroC Ice stubs (`tests/mock_ice.py`)
- **Deployment**: Docker (Debian 12 Bookworm base) & Docker Compose

## 3. Critical Architecture Guardrails

### 3.1 Synchronous `def` for Ice RPC (NON-NEGOTIABLE)
- **Rule**: Route handlers calling ZeroC Ice RPC **must** use synchronous `def`, **never** `async def`.
- **Reason**: ZeroC Ice Python bindings execute blocking socket RPCs. FastAPI dispatches synchronous `def` routes to Starlette's worker threadpool (`run_in_threadpool`), preventing event loop starvation.

### 3.2 Error Handling & Exception Mapping
- **Rule**: Decorate all route handlers with `@handle_ice_errors` from `app.exceptions`.
- **Mappings**:
  - `Murmur.InvalidSecretException` $\rightarrow$ `401 Unauthorized`
  - `Murmur.ServerBootFailedException` $\rightarrow$ `400 Bad Request`
  - `Murmur.ServerCallbackException` $\rightarrow$ `400 Bad Request`
  - `Ice.ConnectionRefusedException`, `Ice.ConnectTimeoutException` $\rightarrow$ `503 Service Unavailable`
  - `Ice.TimeoutException` $\rightarrow$ `504 Gateway Timeout`

### 3.3 Dependency Injection & Lifecycle
- Always obtain Ice Meta via FastAPI dependency: `meta: Murmur.MetaPrx = Depends(get_ice_meta)`.
- Never initialize Ice Communicator at module import time; connection lifecycle is managed in `main.py` lifespan and `app.ice_manager`.

### 3.4 Route Ordering in `app/server_router.py`
- Register **static routes before parameterized routes** to avoid path parameter collisions:
  - Put `/servers/version`, `/servers/deleteServers`, `/servers/userCount` **above** `/servers/{id}`.

### 3.5 Security & Authentication
- Mutating endpoints (`POST`, `PATCH`, `DELETE`) require `_auth: bool = Depends(verify_api_key)`.
- When `API_KEY` is empty in settings, authentication is bypassed for local developer convenience.
- When `settings.MASK_PASSWORDS` is `True`, server passwords in responses must be masked with `"***"`.

### 3.6 Data Serialization
- Use `obj_to_dict` in `app/utils.py` for serializing Slice types and arbitrary objects. It safely handles `None`, primitives, collections, and objects with `__dict__` or `__slots__`.

## 4. Off-Limits
- **Do NOT manually edit `Murmur_ice.py`**: It is auto-generated by `slice2py` from `Murmur.ice`.
- **Do NOT remove legacy backward-compatibility routes**: Keep `/server/getAllServers`, `/server/getServerDetail`, etc., with `include_in_schema=False`.

## 5. Exemplars & Canonical Patterns

### Standard Route Pattern (`app/server_router.py`)
```python
@router.post(
    "/servers/{id}/start",
    response_model=ServerActionResponse,
    summary="Start virtual server",
)
@handle_ice_errors
def start_server(
    id: int,
    meta: Murmur.MetaPrx = Depends(get_ice_meta),
    _auth: bool = Depends(verify_api_key),
):
    server = meta.getServer(id)
    if not server:
        raise HTTPException(status_code=404, detail=f"Server ID {id} not found")
    server.start()
    return ServerActionResponse(
        status="success",
        message=f"Server {id} started successfully",
        server_id=id,
    )
```

### Mock Test Pattern (`tests/test_api.py`)
```python
def test_start_server(client, mock_ice_meta):
    # Mock server behavior is isolated in tests/mock_ice.py
    response = client.post("/servers/1/start")
    assert response.status_code == 200
    assert response.json()["status"] == "success"
```
