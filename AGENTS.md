# AGENTS.md — Development & Agent Guidelines

## 1. Project Overview

`mumble-server-rest-api` is a RESTful API wrapper built with **FastAPI** to manage and administer virtual Mumble servers (**Murmur**) via ZeroC Ice RPC. It is a modern FastAPI reimplementation/successor to the legacy Flask-based `Murmur-REST`.

### Core Technology Stack
- **Framework**: FastAPI (v0.111+), Starlette, Uvicorn
- **Data Validation & Schemas**: Pydantic v2
- **RPC & Integration**: ZeroC Ice 3.7 (`python3-zeroc-ice` / `Ice` Python extension)
- **IDL & Stubs**: Murmur Slice definitions (`Murmur.ice`, `Murmur_ice.py`)
- **Containerization**: Docker (Debian 12 Bookworm base) & Docker Compose
- **Test Harness**: Pytest with mock ZeroC Ice stubs

## 3. Environment & Configuration

Configuration is loaded from environment variables in `settings.py`:

| Variable | Default | Purpose |
| :--- | :--- | :--- |
| `MURMUR_ICE_HOST` | `localhost` | Hostname or IP of the Murmur server running Ice |
| `MURMUR_ICE_PORT` | `6502` | Port for the Murmur Ice interface |
| `MURMUR_ICE_TIMEOUT` | `1000` | Ice invocation timeout in milliseconds |
| `ICE_SECRET` | `""` (empty) | Murmur Ice administrative secret (if configured in `murmur.ini`) |
| `ICE_MESSAGE_SIZE` | `1024` | Maximum Ice message size (KB) |
| `API_KEY` | `""` (empty) | Administrative API Key (optional; accepts `X-API-Key` or Bearer) |
| `MASK_PASSWORDS` | `true` | Masks server passwords in detail responses (`***`) |

## 4. Development Workflow & Running the App

### Running with Docker Compose
To run both the Murmur VoIP server and the REST API connected together:
```bash
docker compose up -d --build
```

### Running Autonomous Verification & Tests
The test suite utilizes mock Ice stubs, allowing tests to run anywhere (including Windows and macOS without native `python3-zeroc-ice` installed):
```bash
# Single-command verification (architecture invariant checks, linting, tests)
make check
# or
python scripts/verify.py

# Run pytest directly
pytest -v
```

### Accessing API Documentation
When running:
- **Interactive Swagger Docs**: `http://localhost:2332/docs`
- **ReDoc Documentation**: `http://localhost:2332/redoc`
- **Health Check**: `http://localhost:2332/healthz`
- **Version Endpoint**: `http://localhost:2332/`

## 5. Architectural Conventions & Guidelines for AI Agents

When editing or extending this codebase, adhere strictly to these conventions:

### 5.1 Synchronous vs Asynchronous Ice Calls
- **CRITICAL**: ZeroC Ice Python bindings execute **synchronous, blocking network socket RPCs**.
- **Rule**: Route functions invoking Ice RPC must use standard synchronous `def` functions. FastAPI automatically dispatches them to Starlette's worker threadpool (`run_in_threadpool`), preventing event loop starvation.

### 5.2 Ice Lifecycle & Connection Management
- Use `app.ice_manager.ice_manager` and `app.ice_manager.get_ice_meta` dependency injection.
- Never place top-level network calls in module definitions. Startup and teardown are orchestrated via the FastAPI `lifespan` handler in `main.py`.

### 5.3 Error Handling
- Wrap routes with `@handle_ice_errors` from `app.exceptions`.
- Ice connection drops map to `503 Service Unavailable` or `504 Gateway Timeout`.
- Secret rejections map to `401 Unauthorized`.
- Server boot errors map to `400 Bad Request`.

### 5.4 API Route Design
- Standard endpoints follow plural RESTful resource patterns: `GET /servers`, `POST /servers`, `GET /servers/{id}`, `DELETE /servers/{id}`, `PATCH /servers/{id}`.
- Action endpoints use sub-resources: `POST /servers/{id}/start`, `POST /servers/{id}/stop`, `POST /servers/{id}/restart`.
- Static endpoints must be registered before parameterized (`/{id}`) endpoints in `server_router.py` to prevent integer path validation conflicts.
- Backward compatibility aliases for legacy `Murmur-REST` query/RPC paths (`/server/getAllServers`, `/server/getServerDetail?id=X`, `/server/deleteServer?id=X`) are maintained with `include_in_schema=False`.

### 5.5 Security
- Passwords must be masked when `settings.MASK_PASSWORDS` is True.
- Modifying routes (`POST`, `PATCH`, `DELETE`) require `_auth: bool = Depends(verify_api_key)`. When `API_KEY` is empty, authentication is bypassed for local development.

### 5.6 Data Serialization (`obj_to_dict`)
- In `app/utils.py`, `obj_to_dict` handles `None`, primitive scalars (`int`, `float`, `str`, `bool`, `bytes`), collections, mappings, and objects with `__dict__` or `__slots__` safely without raising `AttributeError`.
